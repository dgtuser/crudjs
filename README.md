# IP Inventory CRUD

Веб-приложение для инвентаризации и хранения IP-адресов.

## Возможности
- Ручное добавление и редактирование IP записей
- Удаление записей
- Импорт CSV файла
- Поиск и фильтрация по группе/статусу
- Группировка записей по категориям
- Дополнительные поля: DNS, VLAN, подсеть, локация, ответственный, примечания

## Запуск
```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.
